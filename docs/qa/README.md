# Historical release QA records

This directory retains QA records from the former two-stage release-candidate
process. They are historical evidence and are not inputs to the current release
workflow.

New releases are prepared on `main` and published through the single **Create
Release** workflow described in [`../RELEASING.md`](../RELEASING.md). Do not add
a QA-only commit or create a new release record here unless the release process
is deliberately changed again.
